# 📰 Blog Backend API

A Spring Boot-powered REST API for a basic blogging platform. It supports user accounts, posts, and comments, with form-based authentication via Spring Security and in-memory user setup.

---

## 📦 Tech Stack

- Java 17+
- Spring Boot
- Spring Security (form login)
- Spring Data JPA
- H2 Database (in-memory)
- Lombok
